# Exercício 1 — Função ou procedimento? (conceitual)

**Para cada item abaixo, responda se é uma função (retorna um valor) ou um procedimento (apenas executa uma ação) e justifique em uma frase.**

| Item | Resposta | Justificativa |
|------|----------|---------------|
| `Str()` | **Função** | Recebe um dado numérico como parâmetro e retorna sua representação correspondente em formato de texto (string). |
| `QOut()` | **Procedimento** | Executa uma operação de saída de dados no console, alterando a interface sem devolver valor ao fluxo do programa. |
| `Date()` | **Função** | Consulta o relógio interno do sistema operacional e devolve a data corrente como um tipo de dado estruturado. |
| `Len()` | **Função** | Avalia a estrutura de uma string ou array e retorna um número inteiro que representa o total de seus elementos. |
| `Upper()` | **Função** | Processa a cadeia de caracteres informada e retorna uma nova string inteiramente modificada em letras maiúsculas. |
| `ClearScreen()` | **Procedimento** | Realiza um efeito colateral visual ao resetar o terminal, alterando o estado da tela sem gerar dados de retorno. |
